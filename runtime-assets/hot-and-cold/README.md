# Hot and Cold generated data

Judging revision: 1.0.0. Run `pnpm data:hot-and-cold` to rebuild. The lexicon derives from Open English WordNet 2025 (CC BY 4.0) and SUBTLEX-US frequency data. Rank packs are generated with the bundled Xenova/all-MiniLM-L6-v2 model.

The judging revision uses semantic versioning: major changes alter word identity or ranks, minor changes alter official hints or other game rulings without replacing ranks, and patches are metadata-only. Every player-visible result is attached to the exact revision.
