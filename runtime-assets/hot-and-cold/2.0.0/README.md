# Hot and Cold generated data

Judging revision: 2.0.0. Run `pnpm data:hot-and-cold` to rebuild. The lexicon derives from Open English WordNet 2025 (CC BY 4.0) and SUBTLEX-US frequency data. Rank packs are generated with the bundled Xenova/all-MiniLM-L6-v2 model.

Ordinary distributional word association is the main signal. Intended target and ordinary candidate senses provide supporting evidence, WordNet boosts are capped, and alternative-sense-only matches are penalised.
